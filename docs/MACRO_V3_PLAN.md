# Macro v2 — Waves 3 & 4 (resumable plan)

User rules (unchanged): macro inputs from **official sources only** (central banks, statistical offices, Treasuries, Fed banks, BIS/OECD/IMF; FRED/ALFRED counts); approximations OK but labelled; anything model-based is labelled "model-based". Equity prices for Wave 4 come from the existing price lake (they are market data, not macro).
Resume protocol: tick `[x]` + one-line result; state in `data/state/macro_w3.json` / `data/state/macro_w4.json`; long jobs detached + resumable; contracts additive (bump `api.yaml`, log `docs/CONTRACT_CHANGES.md`); re-read shared files before editing (two agents in parallel).
